This repo features my work under the guidance of Dr Misaki Ozawa as part of the Research Intensive Track I, a credit-bearing research project that I am taking during my exchange programme at Université Grenoble Alpes.

The folder `ising` contains my first attempt at coding and executing the Metropolis Monte Carlo algorithm for the Ising model (i.e. spins point either up or down), and finding the critical temperature.

The folder `xy` contains the next iteration, where I expanded the previous work to the XY model (i.e. spins can now point in any angle).
