Second iteration of this project, where I expanded from Ising model to XY model.

The `introduction.ipynb` notebook depicts Metropolis Monte Carlo evolution at an extremely cold temperature with zero external magnetic field for a $15\times15$ lattice.

This set of parameters was chosen so that vortices could be comfortably observed before the spins settle on pointing uniformly in a random direction. If the temperature (or `delta`, for that matter) were higher, the animation would be rather chaotic.

An animation of the exact same conditions for an $80\times 80$ lattice, `xy_colour.gif`, is also included as a standalone file.
